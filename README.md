# 播客章节标注工作台 (Podcast Chapter Studio)

基于 **React + TypeScript + Web Audio API** 的网页播客章节标注工具：导入本地音频后，在可缩放波形上拖拽创建、移动、调整章节区间，自动吸附邻近边界并阻止重叠，支持键盘微调、章节搜索/排序、选中片段实时预览，并导出带章节标题的 **WebVTT** 和 **JSON** 文件；也可一键**导出章节音频包**：按当前章节起止时间从已解码 AudioBuffer 截取片段（左闭右开采样区间，相邻边界不重不漏），保留原声道与采样率编码为 **16-bit PCM WAV**，按时间排序以「序号-标题.wav」命名打成单个 **ZIP** 下载。也支持从本地 **JSON / WebVTT 章节文件导入**：解析后按当前音频时长逐条校验，在预览对话框中标出新增、时间越界、与现有章节重叠等状态，可只应用勾选的有效条目，整次导入为一个可撤销步骤。所有章节编辑（创建、移动、缩放、重命名、删除、「应用全部候选」以及章节文件导入）均记录为**可撤销 / 重做**的可逆操作，工具条按钮与 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 快捷键均可使用，撤销 / 重做不影响当前播放状态。内置**静音切分建议**：按 100ms 窗口分析多声道 RMS，自动在静音中点给出候选切分边界，可一键应用。另内置**章节音量一致性质检**：按 200ms 窗口计算多声道合并 dBFS，以窗口与章节的实际重叠时长加权汇总每章平均音量与动态范围，可自定义过轻 / 过响阈值，异常区间在波形上着色、点击即可从该处预览，并随 JSON 一并导出。支持**章节淡入淡出试听**：每章可独立设置 0～5 秒的淡入 / 淡出时长与开关，预览时按实际播放区间构建增益包络，淡入从静音平滑升至原音量、淡出在章尾前降至静音。另有**连锁移动模式**：锁定任意章节后，拖动 / 缩放未锁定章节会把边界位移原样传递给其后的未锁定章节（间隔与各章时长不变），遇到锁定章节或音频边界自动钳制并提示原因，一次拖拽连带变更整体可撤销 / 重做；锁定状态仅保留在当前会话，不影响导出格式。另支持**逐字稿覆盖核对**：载入本地 WebVTT 逐字稿（字幕仅用于核对、**不作为章节导入**），按字幕与章节的时间交集统计每章有文字覆盖的秒数与占比——越界 cue 先裁剪、重叠 cue 合并去重（同一秒只计一次）、跨章 cue 按相交部分分别计入两章；章节列表与右侧面板实时显示覆盖率，点击相交字幕可跳到该时间试听，编辑章节边界即时重算，切换音频自动清空旧逐字稿。另有**敏感片段消音**面板：导入音频后用播放头分别记录消音起止点（也可直接输入秒数修订），列出、逐条修订并删除多个消音区间；处理时把区间裁剪到音频范围、按采样帧合并重叠或相接区间，起止各带至多 20ms 的衰减 / 恢复包络，输出保持总时长、声道数与采样率不变；面板内可直接试听处理后的完整音频，并下载与试听同源的 **16-bit PCM WAV**，原始缓冲与现有章节导出始终不受影响。

## 一键启动（Docker Compose）

前置条件：已安装 Docker 与 Docker Compose 插件（Docker Desktop / Docker Engine + compose plugin）。

前台启动（日志直接输出到终端，`Ctrl+C` 停止）：

```bash
docker compose up --build
```

或后台守护启动：

```bash
docker compose up --build -d
docker compose logs -f      # 查看日志
docker compose down         # 停止并移除容器
```

启动后在浏览器访问：**http://localhost:8080**（默认宿主机端口 `8080` → 容器内 nginx 监听 `80`）。

宿主机端口可通过环境变量 `PORT` 覆盖，例如改用 `9090`（访问 http://localhost:9090）：

```bash
PORT=9090 docker compose up --build
```

> 不使用 Compose 也可以：`docker build -t chapter-studio . && docker run -p 8080:80 chapter-studio`，然后访问 http://localhost:8080 。
>
> 容器内 nginx 始终监听 **80** 端口，请勿修改映射右侧的容器端口；只调整左侧宿主机端口（`PORT` 或 `-p 宿主端口:80`）。

## 本地开发

```bash
npm install
npm run dev        # Vite 开发服务器，访问 http://localhost:5173 （已对局域网监听 0.0.0.0）
npm test           # 章节吸附/防重叠 + 连锁移动 + 撤销/重做历史 + 静音切分 + 音量质检 + 淡入淡出包络 + 章节文件导入核心逻辑测试 + 逐字稿覆盖核对（裁剪/合并/交集）+ 章节音频包导出（采样截取/WAV 编码/ZIP 打包）+ 敏感片段消音（裁剪/帧合并/≤20ms 包络/等长 WAV）
npm run build      # 产出 dist/（峰值计算代码会被打成独立的 Worker chunk）
```

> 波形峰值计算运行在独立 Web Worker 中；开发与生产构建均由 Vite 直接托管 Worker 产物，无需额外配置。


## 功能与操作

- **导入音频**：点击「导入音频」或把音频文件拖入页面（MP3 / WAV / M4A / OGG 等浏览器可解码格式）。
- **波形缩放**：鼠标滚轮（以光标为锚点）或工具条滑块。
- **创建章节**：在波形空白处按下并拖出一个区间。
- **移动章节**：拖拽章节主体。
- **调整边界**：拖拽章节左右边缘（高亮手柄）。
- **吸附与防重叠**：拖动或调整时，边界在约 10px 内自动吸附到相邻章节边界或文件首尾；所有操作都被钳制在相邻章节之间，不会产生重叠。
- **连锁移动模式**：工具条下方的「🔗 连锁移动」开关切换；也可随时用章节列表项或波形章节旁的 🔒 / 🔓 按钮（或选中后按 `L`）锁定 / 解锁任意章节。
  - 开启后**拖动章节主体**：被拖章节与其后的所有**未锁定章节**作为一串刚性滑块整体平移——各章时长与章间间隔保持不变；向右传递到「其后第一个锁定章节的起点」或**音频结尾**为止，向左不能穿越最近的前序章节或音频开头。
  - 开启后**向右拖右边缘（终点）**：锚点章节伸缩，边缘的位移同样原样传递给后续未锁定章节（它们时长不变、间隔不变）；锚点不会短于 0.2s。**拖动左边缘（起点）**始终只改本章起点、不向后连带。
  - 超出可行范围时，**整次操作被钳制在可行范围内**（绝不产生重叠），波形上在止点处显示琥珀色虚线「墙」（🔒 锁定章节 / 相邻章节 / 音频边界 / 最短时长），页面顶部弹出原因提示；连锁条同步显示「带动 N 个后续章节、位移 ±x.xx s、已钳制于…」的实时摘要。
  - **锁定章节任何模式下都不能被移动或缩放**（光标显示禁止态，波形右上角与列表项均有 🔒 标识），但仍可选中、预览、重命名与删除；锁定只存在于**当前会话**（刷新 / 导入新音频即清空），**不写入章节数据，WebVTT / JSON 导出格式保持不变**。
  - 一次连续拖拽（及其全部连带位移）只算**一个撤销步骤**，`Ctrl/Cmd+Z` 完整恢复锚点与所有被带动章节；键盘微调同样支持连锁与合并撤销。关闭连锁开关后编辑退化为单章行为（锁定保护仍生效）。
- **撤销 / 重做**：章节创建、移动、缩放、重命名、删除、「应用全部候选」以及「章节文件导入」均为可逆步骤；工具条「↶ 撤销 / ↷ 重做」按钮或 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 触发。一次连续拖拽、按住方向键微调或在标题框连续输入只算一个历史步骤；任何新编辑都会清空重做栈（分支即失效），撤销 / 重做只回退章节数据，**不改变当前播放 / 暂停状态与播放头位置，也不改变章节锁定状态**；导入新音频时历史与锁定随章节一并重置。
- **跳转**：单击波形空白处移动播放头。
- **静音切分建议**：右侧面板调节「静音阈值」（-70 ~ -20 dB）与「最短静音」（0.2 ~ 3s），候选边界以橙色虚线旗标实时预览在波形上；候选只落在未被章节覆盖的空白区间，且自动过滤会产生短于 0.2s 章节的边界。点击「应用全部候选」即在空白区间批量生成章节，已有章节保持不变、结果不重叠。
- **章节音量一致性质检**：导入时复用同一份已解码 PCM，按 **200ms 窗口**计算多声道合并 dBFS（仅扫描一次）。右侧面板可设置「过轻阈值」（默认 -30 dBFS）与「过响阈值」（默认 -6 dBFS，两阈值始终保持至少 1 dB 间隔）。
  - 每章按窗口与章节的**实际重叠时长加权**汇总：能量加权平均 dBFS、min/max 与动态范围；全静音章节均值显示 -∞、状态为「过轻（全静音）」，极短 / 零长度章节标记为「过短」，跨章节窗口按重叠拆分归属，绝不产生 NaN 或错误归属。
  - 波形上以**黄色（过轻）/ 粉色（过响）**色块标出连续异常区间（数字静音按过轻处理，底部有实心状态条）；**单击异常色块即从该处开始预览**，拖拽空白照常创建章节。
  - 章节列表每项显示状态徽标（正常 / 过轻 / 过响 / 过短 + 均值），点击徽标从该章首个异常窗口预览；选中章节的详情区显示均值、动态范围与 min/max，并有「从异常处预览」按钮。
  - 调整阈值只对缓存的窗口 dBFS 重新判定，**不会重新解码或重新扫描音频**。
- **搜索 / 排序**：左侧面板按标题搜索，可按开始时间、标题或时长排序。
- **导入章节文件**：页头「导入章节」按钮（与「导出 WebVTT / 导出 JSON」并列，需先导入音频）选择本工具导出的 `*.chapters.json`（或标准 `{ chapters: [...] }` / 章节对象数组）与标准 `*.vtt` 文件（支持 cue 序号、cue 设置、`NOTE/STYLE/REGION` 块、`HH:MM:SS.mmm` 与 `MM:SS.mmm` 时间码、逗号小数、BOM）。
  - 解析后弹出**导入预览**：逐条标出状态——**新增**（可直接导入）、**时间越界**（起点为负或超出当前音频时长）、**重叠**（与现有章节或文件中较早的有效条目重叠）、**无法解析**（时间码非法 / 时长为 0 / 短于 0.2s / 结束早于开始），并给出具体原因；可按「全部 / 可导入 / 问题条目」筛选。
  - 仅**新增（有效）**条目可勾选，默认全选；点「应用」只写入勾选项，**现有章节保持不变**，导入条目自动重建唯一 id、与现有章节合并后按开始时间排序并整体校验不重叠、不出界；空标题按排序后序号补全。「全部取消」或 `Esc` 放弃导入。
  - 应用为**一次可撤销 / 重做操作**（一次 `Ctrl/Cmd+Z` 完整还原）；应用前若最终合并结果存在重叠 / 越界则整体中止并提示，**不会部分写入**。导入新音频会关闭已打开的导入预览。
- **导出章节音频包**：`docker compose up --build` 启动后访问 **http://localhost:8080**，导入音频并标好章节，点页头「导出章节音频包」（与「导出 WebVTT / 导出 JSON」并列，需先导入音频且至少有一个章节）即把每章音频切分打包为 `<音频名>.chapters.zip` 下载。
  - **截取口径**：点击时刻读取**最新章节边界**与**当前已解码 AudioBuffer**；每章起止时间先钳制到 `[0, 音频时长]`，再换算为采样索引，片段为**左闭右开区间** `[startSample, endSample)`——相邻章节共享边界时两侧换算出同一索引，拼接起来**不重复、不漏采样**。
  - **编码格式**：保留原音频的**声道数与采样率**，逐声道交错编码为 **16-bit PCM WAV**；浮点采样钳制到 [-1, 1]（NaN 按 0 处理）。
  - **打包命名**：有效章节按开始时间排序，文件名为 `序号-安全化标题.wav`（序号补零对齐总数宽度，如 `01-intro.wav`；标题中的 `\/:*?"<>|` 与控制字符替换为空格、折叠空白、去首尾点、限长 60 字符，空标题回退为「章节 N」，重名自动追加 `-2`/`-3` 保证不重名），以 store（不压缩）方式打成单个 ZIP。
  - **失败保护**：没有任何可导出片段（章节全部越界 / 零长度）或任一章节编码失败时，页面顶部提示具体原因，**不下载半成品**；只有全部 WAV 与 ZIP 编码成功才触发下载。导出用的是当前音频缓冲与当前章节，**切换音频后不会沿用旧数据**（旧章节随导入重置，缓冲引用同步切换）。
- **逐字稿覆盖核对**：`docker compose up --build` 启动后访问 **http://localhost:8080**，导入音频，在右侧「逐字稿覆盖核对」面板点「载入 WebVTT 逐字稿」选择本地 `*.vtt`。该入口与「导入章节」完全独立：字幕 cue **不会**被当作章节导入，章节数据与导出文件都不受影响（字幕解析失败也不会写入任何章节）。
  - **统计口径**：先把每条 cue 裁剪到 `[0, 音频时长]`（负起点 / 超出音频结尾的部分裁掉，裁剪后无剩余或完全在范围外的丢弃并计数），再把 cue 区间**合并去重**（重叠或首尾相接的区间合一，同一秒只计一次），最后与每章求时间交集：**跨章节的 cue 按相交部分分别计入两侧章节**，绝不整条归到某一章；仅端点相接（零宽度）不计入下一章。
  - 章节列表每项显示 📝 覆盖率徽标（≥90% 绿、≥50% 黄、其余红，悬停可见覆盖秒数与相交字幕条数）；选中章节后面板显示本章覆盖率进度条与**全部相交字幕**（时间为该字幕在本章内的相交片段，长列表可滚动），**点击任意字幕即从该片段起点开始播放试听**（如正在播放则从该时间继续播放）。面板顶部显示合并重叠字幕后的全片覆盖率与参与统计的 cue 数（含跳过 / 越界条数）。
  - 拖动 / 调整章节边界、增删章节、移动或撤销重做后，覆盖率与相交字幕**即时重算**，无需重新载入；**切换音频时自动清空旧逐字稿**（cue 是按旧音频时长裁剪的，不跨文件保留），也可随时点「移除」手动卸载。
- **敏感片段消音**：`docker compose up --build` 启动后访问 **http://localhost:8080**，导入音频，在右侧「敏感片段消音」面板标记要消音的区间，点「生成消音音频」即可试听与下载。
  - **标记区间**：移动播放头后点「记为起点 / 记为终点」分别记录起止，也可直接在输入框中填秒数（步进 0.001s）后点「添加消音区间」；标记后在下方列表按时间列出全部区间，每条可直接改起止秒数（回车或移开焦点生效，越界 / 起止倒置会自动还原）、点 `⤧` 跳到区间起点试听、点 `✕` 删除，也可「全部清除」。**载入新音频时自动清空全部标记**。
  - **处理口径**：点「生成消音音频」时，所有区间先**钳制到 `[0, 音频时长]`**（越界部分裁掉，钳制后零长度丢弃），再换算成采样帧，把**重叠或首尾相接**的区间按帧**合并**（相接也合一，接缝处只留一对包络）；每段消音在起点用线性衰减（原音量 → 0）、终点用线性恢复（0 → 原音量），两侧斜坡各**至多 20ms**（短于 2×20ms 的区间两侧等比缩短、绝不越过区间边界）。输出与原音频**等长、同声道数、同采样率**，区间外采样逐帧恒等。
  - **试听与下载同源**：处理结果只计算一次，面板内「▶ 试听处理后音频」播放的与「下载 WAV」导出的是**同一份处理结果 PCM**；试听中再点按钮停止，点波形或主播放键会停止试听、切回原始缓冲。生成后若又改动了标记，结果区提示「已过期，请重新生成」，避免听到 / 下到旧结果。
  - 点「下载 WAV」得到 `<音频名>.muted.wav`：**完整音频**的 **16-bit PCM WAV**（浮点钳 [-1,1]、NaN→0），总时长、声道与采样率与原文件一致。消音只作用于这份新生成的缓冲，**原始解码缓冲、章节数据以及 WebVTT / JSON / 章节音频包导出均不受影响**；波形上消音区间以红色条带标示。
- **预览**：列表项 ▶、「预览章节」按钮或快捷键 `P` 播放选中章节区间（到点自动停止）。
- **淡入淡出试听**：选中章节后，在右侧详情区开启「预览该章时应用淡入淡出」，分别设置淡入 / 淡出时长（0～5 秒，步进 0.1s）。
  - 预览该章（含「从异常处预览」）时按**实际播放区间**构建增益包络：淡入从静音线性升至原音量，保持后在章尾前线性降至静音，曲线连续、不越过章界。
  - 淡入 + 淡出超过章节长度时，按两者之和**等比例压缩**到刚好铺满整章；面板实时显示压缩后的实际生效时长。
  - 暂停、拖动播放头、重复预览或修改参数都会先停止旧音源并拆除旧包络再重建，不会叠加残留声音；关闭开关立即恢复原始（无淡入淡出）预览。
  - 淡入淡出设置仅为预览用界面状态，不写入章节数据，WebVTT / JSON 导出格式不变。

### 导出 / 导入

- **导出 WebVTT**（`*.vtt`）：标准 `WEBVTT` cue，按开始时间排序，章节标题作为 cue 文本。
- **导出 JSON**（`*.chapters.json`）：`{ version, qualityControl, chapters: [...] }`，时间单位为秒。已导入音频时顶层附带质检参数 `qualityControl: { windowSeconds: 0.2, quietThresholdDb, loudThresholdDb }`，每章附带 `qualityControl`：

```json
{
  "status": "ok | quiet | loud | unknown",
  "meanDbfs": -14.3,
  "minDbfs": -40.0,
  "maxDbfs": -5.0,
  "dynamicRangeDb": 35.0,
  "allSilent": false,
  "silentCoverage": 0.1,
  "quietSeconds": 0.4,
  "loudSeconds": 0.2,
  "analyzedSeconds": 12.3
}
```

全静音章节的 `meanDbfs/minDbfs/maxDbfs` 输出为 `null`（不会输出 `NaN` 或 `Infinity`）。

- **导出章节音频包**（`*.chapters.zip`）：按当前章节起止时间从**当前已解码 AudioBuffer** 截取，时间钳制到音频范围后换算为采样索引，片段为左闭右开区间（相邻章节拼接不重不漏）；保留原声道与采样率编码为 16-bit PCM WAV（44 字节标准头 + 交错 PCM，`fmt/audioFormat=1`）。有效章节按开始时间排序后以「序号-安全化标题.wav」命名（序号补零、标题安全化、重名追加 `-2`/`-3`）打成单个 ZIP（store，文件名 UTF-8，含 CRC32）。章节全部越界 / 零长度或任一片段编码失败时仅提示原因、**不下载半成品**；切换音频后旧章节与旧缓冲同步作废，导出不会沿用旧数据。

- **导入章节文件**：接受上述 JSON 导出文件（顶层也接受裸章节数组、秒数可写成数字或 WebVTT 时间码字符串，多余字段如 `index/duration/qualityControl` 一律忽略）与标准 WebVTT（跳过文件头与 `NOTE/STYLE/REGION` 块，容忍 cue 序号与 cue 设置，剥离标签 / 实体）。逐行解析失败的 cue 不会中断整个文件，而是在预览中列为「无法解析」；每行按当前音频时长与现有章节校验为新增 / 时间越界 / 重叠，文件内部互斥冲突归责给较晚的 cue。应用时只取勾选的有效行，重新生成 id 后与现有章节合并、排序并整体复验（越界 / 过短 / 重叠即抛错放弃，绝不部分写入）。

## 技术要点

- 波形为自绘 Canvas：解码后预计算 200 peaks/s 的 min/max 峰值，任意缩放级别下按像素列聚合渲染，长音频也流畅。**峰值计算运行在独立 Web Worker（`src/audio/peaks.worker.ts`）中**：主线程仅向 Worker **复制**所需声道数据（至多前两个声道的 `Float32Array` 切片，以 transfer 方式移交副本），**不传递、也不转移原 `AudioBuffer`**——解码后的原始 PCM 始终保留在主线程供播放引擎与静音/音量质检使用；计算结果（min/max 两个数组）由 Worker transfer 回来，避免再拷贝。连续切换音频时按单调递增的载入 token 判定：旧解码 / 旧 Worker 任务在每个 `await` 后作废，旧 Worker 直接 `terminate()`（立刻停止 CPU 扫描）并以 `PeaksSupersededError` 拒绝，**只有最新一次载入能更新波形**；Worker 不支持的环境自动退回主线程纯函数；计算失败时已解码 buffer 不丢弃，页面显示可恢复提示并支持「重试计算波形 / 重新选择音频」（`src/audio/peaks.ts` 核心为纯函数 `computePeaksFromPCM`，Worker 与主线程兜底共用同一实现）。
- 静音分析复用已解码的 `AudioBuffer`（不重新解码）：100ms 窗口多声道合并 RMS 只在导入时计算一次；阈值 / 最短静音变化时仅重算静音段与候选边界（`src/audio/silence.ts` 纯函数，由 `scripts/test-silence.ts` 覆盖）。
- 音量质检同样复用导入时已解码的 PCM：200ms 窗口的多声道合并 dBFS 只在导入时计算一次；阈值变化仅对缓存数组重新分类与合并异常区间。章节均值采用能量（重叠时长）加权平均 `10·log10(Σwᵢ10^(dbᵢ/10)/Σwᵢ)`，跨章节窗口按实际重叠拆分归属；静音映射为 `-Infinity`（绝不出 NaN），全静音 / 极短章节均有确定结果（`src/audio/loudness.ts` 纯函数，由 `scripts/test-loudness.ts` 覆盖）。
- 吸附 / 防重叠逻辑集中在 `src/utils/chapterOps.ts` 纯函数中（`moveChapter` / `resizeChapter` / `createChapterInGap` / `findFreeGap`），由 `scripts/test-chapterOps.ts` 覆盖。
- 连锁移动为独立纯函数模块 `src/utils/chainOps.ts`（`chainMoveChapter` / `chainResizeChapter` / `planChainEdit`）：以被编辑章节为锚点构建“连锁串”（其后未锁定章节，遇第一个锁定章节或音频结尾截断），把整串视为刚性滑块统一钳制位移，吸附目标只取不随操作移动的静态边界；左边缘缩放不向后连带；结果携带 `clipped / reason / stop / limitAt` 供 UI 画“墙”与提示。300 组随机锁定 / 拖动 / 缩放的压力断言保证任意结果都不重叠、不出界、不短于最小时长（`scripts/test-chainOps.ts` 覆盖）。
- 撤销 / 重做为快照式历史栈（`src/utils/history.ts` 纯函数：`record` / `undo` / `redo`）：每条记录保存变更前后的章节数组，新记录即清空重做栈，同 `mergeKey` 且在 800ms 合并窗口内的连续编辑（拖拽、键盘连按、标题连续输入）合并为单步，栈深上限 200；由 `scripts/test-history.ts` 覆盖（含一次连锁拖拽的锚点+随动章节整体恢复用例）。历史状态保存在 `useChapters` 的 ref 中（提交时同步镜像章节数据，避免在 React state updater 内产生副作用），导入新音频调用 `reset()` 一并清空，撤销 / 重做不触碰播放引擎与锁定集合。章节锁定与连锁开关为 `useChapters` 中的会话级 state（不进入 `Chapter` 数据、不导出、不参与历史）。
- 章节文件导入为独立纯函数模块 `src/utils/importChapters.ts`（`parseWebVTT` / `parseJSONChapters` / `buildImportPreview` / `applyImportedChapters`）：WebVTT 时间码支持 `HH:MM:SS.mmm`、`MM:SS.mmm` 与逗号小数，逐行解析失败不影响其他 cue；预览按文件顺序把每条 cue 判定为新增 / 时间越界 / 重叠 / 无法解析（与现有章节或较早有效 cue 的互斥冲突归责较晚者，保证有效集合两两不重叠）；应用时只取勾选的有效行，重新生成唯一 id、与现有章节合并排序并整体复验，任何越界 / 过短 / 重叠都抛错且不写入（全有或全无），随后由 `useChapters.replaceAll` 作为**单个历史步骤**提交；由 `scripts/test-importChapters.ts` 覆盖（含本工具 JSON 导出的往返导入与失败不写入用例）。
- 逐字稿覆盖核对为独立纯函数模块 `src/utils/transcriptCoverage.ts`（`parseTranscriptVtt` / `clipTranscriptCues` / `mergeCueIntervals` / `computeTranscriptCoverage`）：解析复用章节导入的 WebVTT 解析器，仅接受 `WEBVTT` 文件（JSON 章节文件被明确拒绝并引导走「导入章节」），坏时间码 / 零时长 cue 跳过并计数；随后按「裁剪到 `[0, duration]` → 合并重叠 cue → 与每章求交集」的流水线统计：秒数取自**合并后并集**与章节的交集（同一秒只计一次），各章相交字幕列表则保留原始 cue 及其在本章内的相交片段（跨章 cue 两侧分别出现、分别只计相交部分，端点零宽度相接不计入）。计算只依赖章节数组与已裁剪 cue，在 App 中以 `useMemo` 随章节编辑即时重算；切换音频在重置章节的同一副作用中清空逐字稿并作废进行中的文件读取；由 `scripts/test-transcriptCoverage.ts` 覆盖（含跨章拆分、重叠去重、越界裁剪、边界相切、边界编辑后重算、章间空档不归责等用例）。
- 章节音频包导出为独立纯函数模块 `src/utils/audioPack.ts`（`chapterToSampleRange` / `encodeWavPcm16` / `buildAudioPackEntries` / `buildZip` / `buildChapterAudioPack`）：时间先钳制再按采样率取整、左闭右开 `[startSample, endSample)` 保证相邻章节边界不重不漏；WAV 为手写 44 字节头的 16-bit PCM（保留原声道与采样率，浮点钳 [-1,1]、NaN→0），ZIP 为手写 store 归档（local + central directory + EOCD，CRC32 校验、文件名 UTF-8、输出确定可复现），不引入第三方依赖；有效章节按时间排序、序号补零、标题安全化且重名自动加后缀；无可导出片段或编码失败统一抛错，UI 只提示原因、不触发下载。导出在点击时同步读取「当前章节 state + `currentBufferRef` 中的当前 AudioBuffer」，切换音频时二者一起重置，绝不沿用旧数据；由 `scripts/test-audioPack.ts` 覆盖（钳制/半开区间拼接恒等、WAV 头与交错 PCM、ZIP 结构往返解析与 CRC32、排序/命名/去重、各失败路径）。
- 淡入淡出包络为纯函数（`src/audio/fade.ts`：`fitFadeTimes` 等比例压缩、`buildFadeCurve` 生成曲线关键点），由 `scripts/test-fade.ts` 覆盖；播放时 `AudioEngine` 为每次预览挂一个独立的 `GainNode` 包络（source → envelope → 主增益），停止 / 重建时取消自动化并断开节点，杜绝残留声音。
- 敏感片段消音为独立纯函数模块 `src/audio/muting.ts`（`regionToFrameRange` / `mergeFrameRanges` / `prepareMuteRanges` / `applyMuting` / `encodeMutedWav` / `clampMuteRegion`，另含 DOM 助手 `pcmToAudioBuffer`）：秒级区间先钳制再换算采样帧（左闭右开），按帧合并重叠**与相接**区间（`a.end === b.start` 也合一）；每段包络两侧各 ≤20ms（`maxFade = round(0.02·rate)`，短于 2×maxFade 时 `floor(span/2)` 与余量分别给衰减 / 恢复，恰好铺满、绝不越界）；输出是与原缓冲等长的新 `Float32Array`，区间外逐帧恒等、NaN 在区间内归零（区间外交给 WAV 编码层按 0 处理）。WAV 编码直接复用 `audioPack.encodeWavPcm16`（全长 16-bit PCM，声道 / 采样率不变）。处理结果 `MutedPcm` 在 App 中只计算一次并缓存：试听经 `pcmToAudioBuffer` 载入 `AudioEngine`（新增 `setPlaybackBuffer` 切换播放缓冲、`play` 接受指定缓冲），下载用同一份 PCM；标记任何增删改都通过快照比较把结果置为过期并停止试听。标记与会话级状态在导入新音频的同一时刻清空，`currentBufferRef`（原始缓冲）与章节数据从不被修改；由 `scripts/test-muting.ts` 覆盖（钳制 / 相接帧合并 / 短区间包络铺满 / 区间外恒等 / 立体声 / NaN / WAV 等长往返 / 校验）。
- 播放基于 Web Audio API：`AudioBufferSourceNode` 支持带结束点的片段预览，播放头由 rAF 驱动。
- Docker 为多阶段构建：`node:20-alpine` 构建 → `nginx:1.27-alpine` 托管静态文件。
